# Proyecto-Ejecutable-V1.1
- He aquí un proyecto hecho por dirección mía, el cual, permite calcular diferentes cosas, tal y como en la V.1.0, en la cual, combina 4 asignaturas escolares (Matemáticas, Física, Química, Biología), en donde tú seleccionas la fórmula en la que quieras trabajar.
- Actualmente tiene más de 10 fórmulas en general para cada materia, incluyendo una calculadora científica y una calculadora de masa molar exacta.
Punteos de la actualización 1.1:
- Ahora, hay operaciones aritméticas básicas para vectores (suma,resta,multiplicación y división).
- El programa ahora tiene soporte para 3 idiomas extras al español (Alemán, Inglés y Portugués).
- Nuevas fórmulas de volúmenes y áreas de figuras/formas geométricas básicas.
- Se añadió la fórmula general para funciones cuadráticas.
- Por último, hay una calculadora científica disponible para todo uso.
